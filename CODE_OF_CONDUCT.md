# Code of conduct

Treat people with respect. Critique ideas and code constructively, assume good intent, and make room for different experience levels and backgrounds.

Harassment, threats, discriminatory language, sexual content directed at others, doxxing and deliberate disruption are not acceptable. Do not publish private information without permission.

These expectations apply to issues, pull requests and other project spaces. Maintainers may edit or remove inappropriate content, lock discussions or restrict participation. Responses should be proportionate to the behaviour and its effect on others.

Use GitHub's **Report content** action to report inappropriate content. For non-sensitive project concerns, open an issue without private details. Do not repeat private or abusive content publicly to make a report.
