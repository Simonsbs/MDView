# Support

Read the [installation guide](docs/installation.md). For bugs, open a [bug report](https://github.com/Simonsbs/MDView/issues/new?template=bug_report.yml) with the version, OS, package type and minimal reproduction.

Use the [feature request form](https://github.com/Simonsbs/MDView/issues/new?template=feature_request.yml) for improvements. The project prioritises a simple viewing experience.

Support is provided through GitHub on a best-effort basis. Remove private paths, documents and credentials from shared material. Vulnerabilities use [private reporting](SECURITY.md).
